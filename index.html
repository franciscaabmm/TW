Instruções

Objetivo: Capturar todas as peças do adversário.

Como Jogar:

  1. Lance o dado de paus
  2. Selecione uma peça para mover
  3. Clique no destino

Regras Especiais:

  • Peças não movidas só podem mover com 1 (Tâb)
  • Peças na última linha só podem mover quando todas as outras já saíram da base
